# Цветочный магазин (FlowerShop)

Онлайн-витрина цветочного магазина: каталог букетов, корзина, оформление заказа,
бронирование на дату и панель управления для сотрудников.

Версия: 1.0  
Статус: релиз  
Стек: Python (Django) / PostgreSQL / Redis  
Команда: [ссылка на список команды]

---

## 1. Назначение

Проект решает две задачи:

**Для покупателей**
- выбрать букет в каталоге (фильтры по поводу, цене, цветам);
- оформить заказ с доставкой или самовывозом;
- забронировать букет к нужной дате и времени.

**Для магазина**
- вести каталог товаров и наличие;
- управлять заказами: статусы, подтверждение, история;
- смотреть отчёты по продажам.

Что НЕ входит в v1.0: доставка собственным курьером с трекингом,
программа лояльности, интеграция с 1С. Планируется в v1.1+.

## 2. Установка и запуск

### Требования
- Python 3.11+
- PostgreSQL 14+
- Redis 6+
- Docker и Docker Compose (рекомендуется)

### Вариант 1. Через Docker (рекомендуется)

```bash
git clone https://git.example.com/company/flowershop.git
cd flowershop
cp .env.example .env          # заполнить переменные окружения
docker compose up -d --build
docker compose exec web python manage.py migrate
docker compose exec web python manage.py createsuperuser
Приложение доступно по адресу: http://localhost:8000 Админ-панель: http://localhost:8000/admin

Вариант 2. Локально, без Docker
bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env           # указать строку подключения к БД
python manage.py migrate
python manage.py runserver
Переменные окружения (.env)
Переменная	Пример значения	Описание
SECRET_KEY	произвольная длинная строка	ключ Django
DEBUG	False	режим отладки
DATABASE_URL	postgres://...	подключение к базе данных
REDIS_URL	redis://localhost:6379/0	кеш и очереди
PAYMENT_API_KEY	выданный провайдером ключ	платёжный шлюз
3. Основные сценарии
Покупатель
Просмотр каталога — открыть главную страницу, применить фильтры (повод, цена, состав), открыть карточку букета.
Оформление заказа — добавить букет в корзину, указать имя, телефон, дату и время доставки, комментарий, подтвердить заказ.
Оплата — перейти по ссылке на платёжный шлюз, оплатить, вернуться на страницу подтверждения.
Личный кабинет — посмотреть статус заказа и историю покупок.
Администратор магазина
Вход в админ-панель — /admin, логин и пароль суперпользователя.
Управление каталогом — добавить/скрыть букет, указать цену, фото и наличие.
Обработка заказов — сменить статус (новый → подтверждён → собран → доставлен), связаться с клиентом по указанному телефону.
Экспорт отчёта — выгрузить список заказов в CSV за выбранный период.
4. Частые вопросы (FAQ)
Заказ не оформляется, ошибка «Сервис оплаты недоступен».
Проверьте переменную PAYMENT_API_KEY и статус шлюза. Логи: docker compose logs web.

Букет не отображается в каталоге.
Убедитесь, что товар активен и указана цена. Кеш каталога обновляется раз в 5 минут, или сбросьте его: docker compose exec web python manage.py clear_cache.

Не приходят письма о заказе.
Проверьте настройки SMTP в .env (EMAIL_HOST, EMAIL_PORT, EMAIL_HOST_USER).

Как сбросить пароль администратора?
docker compose exec web python manage.py changepassword <логин>

Где хранятся загруженные фото?
В папке media/ (или в S3-совместимом хранилище, если задан S3_BUCKET).
