## Встреча №1 (Спринт 1 — планирование и согласование ТЗ)

**Дата:** 20.11.2026  
**Время:** 10:00–12:00  
**Формат:** онлайн (Zoom)  
**Присутствующие:** Анна (PM), Борис (аналитик), Виктор (разработчик), Галина (заказчик)  
**Отсутствующие:** Дмитрий (дизайнер) — больничный  

### Цели встречи
- Согласовать назначение и границы проекта.
- Утвердить функциональные и нефункциональные требования.
- Зафиксировать основные сценарии использования.
- Определить критерии приёмки для v1.0.

### Ключевые обсуждения
- **Назначение проекта:** онлайн-витрина + корзина + бронирование букетов + CRM для флористов.
- **Функциональные требования:** каталог с фильтрами, корзина, оформление заказа, личный кабинет, админ-панель.
- **Нефункциональные требования:** время отклика < 2 сек, мобильная адаптивность, доступность (WCAG), безопасность платежей.
- **Ограничения:** интеграция только с одним платёжным провайдером; без сложной логистики на v1.0.
- **Сценарии:** просмотр каталога, подбор букета, бронирование на дату, подтверждение менеджером, оплата.

### Принятые решения
- ТЗ фиксируется в README.md + отдельные user stories в трекере.
- Приоритет на MVP: каталог + корзина + оформление + админ-панель для статусов.
- Платёжный шлюз — по спецификации провайдера; безопасность — HTTPS + токены.

### Действия (Action items)

- Собрать макеты экранов (Дмитрий) — до 22.11.
