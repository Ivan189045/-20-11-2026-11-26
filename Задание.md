# 🌷 Flower Shop — учебный проект «Цветочный магазин»

Веб-приложение интернет-магазина цветов: каталог букетов,
корзина, оформление заказа и панель администратора.

## Стек
- Язык: Python 3.11 (или ваш)
- Фреймворк: Flask (Django, FastAPI — что используете)
- БД: SQLite / PostgreSQL
- Фронтенд: HTML, CSS, JavaScript

## Возможности
- [x] Каталог товаров с фильтрами
- [x] Корзина и оформление заказа
- [x] Регистрация и вход пользователя
- [x] Админ-панель: товары и заказы
- [ ] Собери свой букет (в планах)
